**Examen:** [[O03]] (Ordinaria 2003) · **Puntos:** 2 · **Tipo:** problema · **Temas:** [[T08]], [[T09]]

> [!question] Enunciado
> 6. La empresa MICSA presenta al final del año las siguientes partidas del balance en miles de euros: Capital 16.400, Bancos 1.000, Clientes 800, Préstamos a largo plazo 5.250, Mercaderías 4.000, Maquinaria 5.000, Elementos de transporte 2.500, Proveedores 2.150, Construcciones 8.500, Terrenos 2.000.
> Con la información anterior se pide:
> a) Ordene las anteriores partidas del balance (0,5 puntos).
> b) Calcule los siguientes ratios y comente su significado (1 punto):
> - Ratio de tesorería = (Disponible + Realizable) / Exigible a corto plazo
> - Ratio de liquidez o solvencia financiera = (Disponible + Realizable + Stock) / Exigible a corto plazo
> c) Analice y comente la situación financiera de la empresa MICSA según el balance anterior (0,5 puntos).

## Solución

> [!note] Solución propia (no hay solución oficial publicada para esta convocatoria).

**a)** (miles de €)

| ACTIVO | | PATRIMONIO NETO Y PASIVO | |
|---|---:|---|---:|
| **Activo fijo** | **18.000** | **Fondos propios** | **16.400** |
| Terrenos | 2.000 | Capital | 16.400 |
| Construcciones | 8.500 | **Exigible a largo plazo** | **5.250** |
| Maquinaria | 5.000 | Préstamos a largo plazo | 5.250 |
| Elementos de transporte | 2.500 | **Exigible a corto plazo** | **2.150** |
| **Activo circulante** | **5.800** | Proveedores | 2.150 |
| Existencias (mercaderías) | 4.000 | | |
| Realizable (clientes) | 800 | | |
| Disponible (bancos) | 1.000 | | |
| **Total activo** | **23.800** | **Total PN + pasivo** | **23.800** |

**b)**
- Tesorería = $\frac{1.000 + 800}{2.150} =$ **0,84**: sin vender existencias, solo podría pagar el 84 % de las deudas a corto.
- Liquidez = $\frac{5.800}{2.150} =$ **2,70**: el activo circulante cubre casi tres veces las deudas a corto.

**c)** FM = 5.800 − 2.150 = 3.650 → **equilibrio financiero** holgado y poca deuda. Su liquidez depende mucho de las existencias (4.000): un exceso de stock que inmoviliza recursos; conviene vigilar la rotación de mercaderías para no tener tensiones de tesorería.
