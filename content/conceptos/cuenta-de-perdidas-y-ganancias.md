**Tema:** [[T08]] · **Tipo:** problema · **Relacionado:** [[rentabilidad-economica-y-financiera]], [[balance-de-situacion]], [[cuentas-anuales]]

## Qué es

Documento de las cuentas anuales que recoge los **ingresos y gastos** del ejercicio y el **resultado** obtenido (beneficio o pérdida). Es un estado de **flujos** (todo el año), frente al balance, que es una foto en una fecha.

## Estructura (PGC simplificado)

| | |
|---|---|
| Ingresos de explotación (ventas, otros ingresos de explotación) | + |
| Gastos de explotación (compras/aprovisionamientos, sueldos, seguridad social, alquileres, suministros, publicidad, transportes, **amortización del inmovilizado**…) | − |
| **A) Resultado de explotación (BAII)** | |
| Ingresos financieros (intereses cobrados) − gastos financieros (intereses pagados) | |
| **B) Resultado financiero** | |
| **C) Resultado antes de impuestos (BAI) = A + B** | |
| Impuesto sobre beneficios (t × BAI, solo si BAI > 0) | − |
| **D) Resultado del ejercicio (beneficio neto)** | |

El **BAII** se usa para la rentabilidad económica; el **resultado del ejercicio**, para la financiera. (EBITDA = BAII + amortizaciones.)

## Errores típicos

- Meter los **intereses** en el resultado de explotación.
- Restar el **impuesto** cuando hay pérdidas.
- Olvidar la **seguridad social a cargo de la empresa** o los ingresos financieros (intereses cobrados).
- Confundir el alquiler (gasto de explotación) con gasto financiero.
