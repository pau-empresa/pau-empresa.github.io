## Qué es

| Concepto | Fórmula | Ejemplos |
|---|---|---|
| **Coste fijo (CF)** | No depende de la cantidad producida | Alquiler, salarios fijos, amortización, seguros, intereses |
| **Coste variable (CV)** | $CV = CV_u \cdot Q$ | Materias primas, energía de producción, comisiones, embalajes |
| **Coste total** | $CT = CF + CV_u \cdot Q$ | |
| **Coste total medio (unitario)** | $CTMe = CT/Q$ | |
| **Coste fijo medio** | $CFMe = CF/Q$ (baja al aumentar Q: economías de escala) | |
| **Coste variable medio** | $CVMe = CV/Q$ (= CV<sub>u</sub> si es constante) | |
| **Coste marginal** | Coste de una unidad más (= CV<sub>u</sub> si es constante) | |
| **Ingreso total** | $IT = P \cdot Q$ | |
| **Beneficio** | $B = IT - CT = (P - CV_u)\,Q - CF$ | |

Otras clasificaciones: **directos/indirectos** (imputables o no a un producto concreto). **Compra ≠ coste ≠ pago**: la compra de materia prima no es coste hasta que se **consume**; el pago es un movimiento de tesorería ([[O09-A3]]).
