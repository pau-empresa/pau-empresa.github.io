## Qué es

| Modelo | Rasgos | Ventajas / inconvenientes |
|---|---|---|
| **Lineal o jerárquico** | Unidad de mando: cada trabajador depende de **un solo jefe** | Sencillo y claro / rígido, sobrecarga a los jefes; para pymes |
| **Funcional** (Taylor) | Especialistas por funciones; un trabajador recibe órdenes de **varios** especialistas | Especialización / se rompe la unidad de mando, posibles conflictos |
| **En línea y staff** (asesoramiento) | Estructura lineal + órganos **staff** que asesoran **sin autoridad** (asesoría jurídica) | Mantiene la unidad de mando con apoyo experto / tensiones línea-staff |
| **Matricial** | Doble dependencia: departamento funcional y **proyecto** | Flexibilidad, para proyectos / dos jefes, conflictos |
| **En comité** | Decisiones tomadas colectivamente por varios responsables | Decisiones consensuadas / lentitud, responsabilidad diluida |
| (Divisional) | Divisiones por productos o mercados | |

**Relación lineal vs. staff** ([[O19-A2]]): lineal = autoridad para mandar; staff = asesoramiento.

**¿Motiva una estructura lineal?** Probablemente no: es rígida y poco participativa ([[E04-B3]]).
