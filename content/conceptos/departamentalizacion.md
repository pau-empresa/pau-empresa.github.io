## Qué es

Agrupar tareas y personas en **departamentos** según un criterio, para coordinar el trabajo.

| Criterio | Ejemplo |
|---|---|
| **Por funciones** | Producción, marketing, finanzas, RR. HH. |
| **Por productos** | División de electrodomésticos, división de telefonía |
| **Por zonas geográficas** | Delegación norte, sur; Europa, América |
| **Por procesos** | Corte, montaje, pintura, control de calidad |
| **Por clientes** | Particulares, empresas, administraciones |
| (Por proyectos, matricial) | |
